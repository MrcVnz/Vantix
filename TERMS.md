## System changes

Only apply changes to computers you own or are authorized to administer. Read each action's description, keep backups of important files and check the result before making further changes.

Vantix includes restore-point and change-history features, but these are not a complete backup. Some actions delete data, interrupt connections or change security and power settings. Recovery can fail, and not every operation can be undone.
